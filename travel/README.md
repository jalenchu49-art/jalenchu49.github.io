# 在路上 · 旅行手记

独立的中文旅游网站，入口为 `travel/index.html`，不修改上级目录的学术主页。使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。

## 本地运行

在仓库根目录运行 `python3 -m http.server 8000`，访问服务的 `/travel/` 路径。

## 内容与功能

- `app.js` 中的 `groups` 保存作者提供的 40 个目的地及其地区分类。
- 地区筛选、目的地搜索、渐进展开、目的地详情、通用攻略和可勾选行前清单。
- 收藏和清单状态保存在当前浏览器的 localStorage 中，不跨设备同步；禁用存储时不影响浏览。
- 配图为内嵌 SVG 风景插画，不是目的地实拍。目的地故事、真实照片、日期、路线、预算均待作者提供。
- 目前是静态网站，没有后台内容编辑器或用户账户。修改内容需要编辑源文件。

## 上线

当前仓库已经使用 GitHub Pages。将 `travel/` 提交并推送到已配置的发布分支后，本网站使用原网站地址下的 `/travel/` 路径。发布配置与学术主页无需变更。如需独立域名或单独仓库，可后续迁移此目录。
